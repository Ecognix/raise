MASTER DEVELOPMENT PROMPT – RAISE AI INTELLIGENCE PLATFORM

Project: RAISE – Road Asset Intelligence and Safety Engine
Objective: Upgrade the existing RAISE software into a futuristic, AI-powered road infrastructure monitoring and maintenance platform.

1. Overall Development Instructions

First, inspect the existing RAISE project, its codebase, architecture, components, database and existing functionality.

Do not rebuild the application from scratch. Integrate all new features into the existing software while preserving its existing working modules.

The software should look like a premium government-grade infrastructure intelligence platform, combining the aesthetics of Palantir, modern GIS systems, Tesla software interfaces and advanced AI command centres.

The interface must be:

- Futuristic but professional.
- Minimalistic and easy to navigate.
- Highly interactive.
- Responsive on desktop, tablets and mobile.
- Fast and smooth, with subtle animations.
- Visually impressive during government demonstrations.

Create an interactive visual representation of the entire Hirakjyoti Kakati Road.

C. Examine Pothole – MAIN AI FEATURE

This is the most important feature.

Display multiple pothole photographs in an inspection gallery.

Every photograph should have a prominent button:

EXAMINE POTHOLE

When the user clicks this button, initiate an AI analysis workflow.

The workflow should:

1. Load the selected pothole photograph.
2. Perform image preprocessing.
3. Detect the pothole using computer vision.
4. Segment the damaged region.
5. Estimate its boundaries.
6. Generate an interactive 3D-style pothole visualisation.
7. Calculate dimensions where sufficient scale or depth information is available.
8. Estimate damaged surface area.
9. Classify pothole severity.
10. Generate an AI inspection report.

D. 3D Pothole Visualisation

After clicking EXAMINE POTHOLE, open a dedicated analysis interface.

The left panel should display the original pothole photograph.

The central panel should display an interactive 3D representation of the pothole.

The right panel should display its measurements and AI assessment.

The 3D visualisation should include:

- Pothole depth representation.
- Length and width.
- Damaged surface area.
- Boundary segmentation.
- Depth colour gradients.
- Surface irregularities.
- Interactive rotation.
- Zoom and pan controls.
- 3D grid and measurement indicators.

Use Three.js or React Three Fiber for the 3D rendering.

Make the visualisation look like a professional engineering inspection tool.

IMPORTANT: A single ordinary 2D photograph cannot reliably establish real-world depth or physical dimensions without calibration, scale references, depth data or additional views. Clearly distinguish actual measurements from AI estimates. Never fabricate precise engineering measurements. Where data is insufficient, show estimated or unavailable measurements and explain what additional input is needed.

E. AI Analysis Results

Display an inspection report containing:

- Defect identification.
- Defect classification.
- Severity: Low / Moderate / High / Critical.
- Estimated length.
- Estimated width.
- Estimated depth, if measurable.
- Damaged surface area.
- AI confidence score.
- Recommended maintenance action.
- Maintenance priority.

Provide a button to export the analysis as a PDF inspection report.
